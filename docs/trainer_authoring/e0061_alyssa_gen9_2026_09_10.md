## Shared Tailwind scoring repair

Observed failure: a Cyclizar/Fletchinder board with Gligar in reserve chose
Tailwind against Sableye44/Pachi71 despite all three NPCs already being faster
(108/85/85), no wind-activation ability and no Electro Ball. Merely awarding
zero speed bonus did not prevent a recoil-free idle action from winning.

`src/battle_ai_main.c` now applies the existing20-point no-payoff penalty in
the doubles Tailwind viability branch when both the computed speed-order score
and native wind-ability payoff are zero, and the side lacks Electro Ball.
This reuses existing facts rather than adding another evaluator or simulating
future turns. Positive native Wind Rider/Wind Power scores and Electro Ball
are excluded from that penalty. These exceptions are source-reviewed; this
encounter is not independent execution proof for those other abilities.
`src/battle_ai_pair.c` also counts a current speed tie as a useful Tailwind
crossing (`<=`), matching the native viability calculation. Existing active
Tailwind and Trick Room handling remain. This is a scoring correction, not
an absolute claim that no future edge case can select questionable Tailwind.

One necessary retained native regression, `EC Tailwind: faster recoil attackers
do not use empty speed setup`, reproduces the old board independently of
Alyssa's evolving roster. It generates actual Gen9 stats, verifies that all
three NPCs are faster, and checks that Tailwind's PP is not spent. This is a
demonstrated failure check, not a desired-move script for every trainer.

- `work/alyssa-tailwind-regression-fixed.log`: PASS.
- `work/alyssa-tailwind-regression-counterfactual.log`: removing only the new
  penalty makes the same fixture FAIL, with Tailwind PP14 instead of15.
- The penalty was restored before final verification. Useful Tailwind still
  executes against faster Crobat in the promoted Flying-pair control below.

No new runtime allocations, tables, recursion or search depth. The single
regression remains; encounter-review scratch scenarios are excluded afterward.
