# Emerald Champions

Emerald Champions is a challenge-focused Pokémon Emerald ROM hack built with
the [**pokeemerald decompilation project**](https://github.com/pret/pokeemerald)
and the [**RHH pokeemerald expansion**](https://github.com/rh-hideout/pokeemerald-expansion).

The game emphasizes difficult bespoke trainer battles, open team building,
strict level caps, Mega Evolution, modern competitive tools, and a native GBA
presentation.

## Credits

Emerald Champions builds on prior community work by BuffelSaft and many ROM-hack
contributors, as well as the pokeemerald and pokeemerald-expansion projects.

## Build

Use the checked-in build and verification workflows. Generated ROM binaries are
release artifacts and are not committed to this source-only repository.
